# 학습 기록 구조 (프롬프트 D, 2026-11-15)

아르카 연대기가 학생의 공부 기록을 어떻게 모으고, 나중에 Pesk(Firebase)로 어떻게 보낼지 적은 문서예요.
코드: `src/19-log.js`(기록·보고서), `teacher.html`(학급 모아 보기), 검사 `tools/check/log.cjs`.

## 1. 어디에 저장하나
- 브라우저 localStorage 키 **`arca-log`**. 게임 저장(`arca-v2`)과 **따로** 둬요. 게임을 '처음부터' 해도 학습 기록은 남아요.
- 버전 번호 `v`(지금 1). 구조를 바꾸면 `v` 를 올리고, 옛 기록을 바꾸는 코드를 함께 넣어요.
- **개인정보 없음**: 실명·학번·이메일을 넣지 않아요. 보고서와 내보내기에는 게임 속 별명(`save.name`, 8자)만 나가요.

## 2. 모양
```js
arca-log = {
  v: 1,
  recent: [            // 최근 300문제는 한 문제씩
    { d: "2026-11-15",   // 날짜(기기 시각)
      p: 1,              // 부(1~12) = 단원 순서
      u: "5-1 1단원 자연수의 혼합 계산",  // 단원 이름(문제 은행의 unit), 지문은 "지문 · 제목", 영어는 "영어 단어"
      k: "math",         // 유형: math 수학 · eng 영어 · read 지문
      ok: 1,             // 처음 고른 답이 맞았는지(1/0)
      t: 4,              // 걸린 시간(초, 0~600)
      re: 0,             // 다시 만난 문제(오답 노트에서 다시 나온 것)인지
      q: "계산해 보세요. 2 × (9 + 9)",  // 문제 글(200자까지)
      a: "36" }          // 정답(40자까지)
  ],
  agg: {               // 300문제보다 오래된 것은 날짜·유형·단원별 합계로 접음
    "2026-11-01|math|5-1 1단원 …": { d, p, u, k, n: 문제 수, ok: 맞힌 수, t: 시간 합(초), re: 다시 만난 수 }
  },
  miss: {              // 자주 틀린 문제(최대 60개, 많이 틀린 것부터 남김)
    "<문제 글>": { a: 정답, u: 단원, n: 틀린 횟수, last: 마지막으로 틀린 날, fix: 다시 맞혔으면 1 }
  }
}
```
- 무엇을 세나: 길 위 전투(약점 구슬·문제 상자·숫자 판), 문제 상자(첫 수련·'풀어 주기' 퀘스트), 지문 확인 문제. **처음 고른 답만** 세요(마법사 '다시 생각'이나 다시 누르기는 틀린 것으로).
- 크기: 300문제 + 합계 + 틀린 문제 60개 ≈ **30KB 안팎**(검사에서 350문제 27KB). 1년 내내 써도 크게 늘지 않아요(합계는 날짜×단원 수만큼).

## 3. 내보내기 묶음 (학습 보고서 → 기록 내보내기)
```js
{ app: "arca", v: 1, nick: "별빛7", at: "2026-11-15T…Z", grade: 5,
  progress: { part, towns, lv, solved, recov, bestCombo, job },
  log: <위의 arca-log 그대로> }
```
- JSON 파일 하나 = 학생 한 명. 표(CSV)는 날짜·부·단원·유형별 합계(엑셀에서 바로 열림, UTF-8 BOM).
- 아티팩트(플레이 링크)처럼 파일 저장이 막힌 곳에서는 글 상자에 보여 주고 복사 버튼을 줘요. 그 글을 `teacher.html` 의 '글로 붙여 넣기'에 넣으면 돼요.
- `teacher.html`: 같은 별명 + 같은 첫날이면 같은 학생으로 보고 새 파일로 바꿔요.

## 4. Pesk(Firebase) 로 보낼 때 (제안 — Pesk 파일은 아직 고치지 않음)
Pesk 는 학급 데이터를 `classrooms/{학급}/data/{키}` 에 두고, 학생마다 나누는 기록은
`classrooms/{학급}/data/pesk-quiz-progress/students/{학생번호}` 처럼 **학생별 하위 문서**로 써요(`firestore.rules` 의 `match /data/{key}/students/{studentId}`).

**문서 경로 제안**: `classrooms/{학급}/data/arca-log/students/{학생번호}`
- 문서 내용 = 3번의 내보내기 묶음에서 `nick` 대신 Pesk 학생 번호를 쓰면 돼요(이름은 Pesk 가 이미 알고 있음).
- 한 문서 크기 한도는 1MB → 30KB 라 넉넉해요. 문제 하나마다 쓰지 말고 **마을에 들어갈 때·게임을 닫을 때·5분마다** 한 번씩 합쳐 쓰기(쓰기 횟수 절약).
- 여러 기기에서 하면 `recent` 를 날짜+문제 글+시각으로 합쳐(중복 빼기) 써요. 그래서 나중에 `recent` 에 시각(`ts`)을 더할 예정 → 그때 `v: 2`.

**보안 규칙에서 볼 점** (Pesk 쪽 `firestore.rules` 에 더할 블록, 지금 `pesk-quiz-progress` 와 같은 모양):
- 읽기: 그 학급 선생님(`ownsRoom`)·관리자, 그리고 **학생 본인 문서만**(`studentId` 가 로그인한 학생과 같을 때). 지금 `pesk-quiz-progress` 는 학급 학생 모두가 읽을 수 있게 열려 있는데, 학습 기록은 친구가 보지 못하게 **본인만**으로 좁히는 것을 권해요.
- 쓰기: 학생 본인 문서만, 크기 제한(`request.resource.size < 200000` 정도), `app == "arca"` 확인.
- 보안이 걸리지 않은 학급(`!isSecuredRoom`)에서는 아무나 쓸 수 있으니, 학습 기록은 **보안 학급에서만** 켜는 것을 권해요.
- 이름·학번은 문서에 넣지 않기(경로의 학생 번호로 충분).

## 5. 선생님 보고서에 보이는 것 (게임 위 「학습 보고서」, 휴대폰은 메뉴 → 선생님 설정 → 학습 보고서 보기)
- 요약: 푼 문제, 정답률, 공부한 날, 진도(부·되살린 마을·Lv), 되찾은 기억(다시 맞힌 문제).
- 최근 7일 막대(숫자도 함께).
- 단원별 표: 문제 수·정답률·평균 시간. **5문제 이상 풀었는데 60% 아래면 ▼ + 굵게 + 빨간 바탕**(색만으로 구분하지 않음).
- 자주 틀리는 문제 5개(아직 다시 맞히지 못한 것): 문제 글·정답·틀린 횟수·단원.
- `teacher.html`(학급 모아 보기): 학생별 표(정답률 ▼ 기준 20문제·60%)와 단원별 학급 평균(▼ 기준 10문제·60%), 학급 표 CSV 저장.

## 6. 2026-11-15 더한 칸 (버전 v 는 그대로 1 — 새 칸만 더함)
- `arca-log.retry = { n, ok }`: 틀린 뒤 '다시 풀기' 횟수와 그중 맞힌 수(처음 답만 세는 `recent` 에는 들어가지 않음).
- `arca-log.hints`: 전투 중 「?」(핵심 한 줄)를 본 횟수.
- 내보내기 `progress.caps`(단원 마무리 ★ 도장을 받은 부 번호들)·`progress.lessons`(들은 수업 수)·`progress.fast`(찍기 보호막이 뜬 횟수). `teacher.html` 학생 표에 '마무리 ★' 칸.
- 문제의 걸린 시간 `t` 는 **답을 고른 순간까지**(풀이를 읽는 시간은 빼요).
