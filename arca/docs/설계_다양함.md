# 설계안 · 마을·길목·퀘스트 다르게 (프롬프트 O, 2026-11-15) — 선생님 확인 전

## 왜
- 2~12부 마을은 같은 생성기(`genTown`)라 광장·지워진 곳·건물 배치가 거의 같고 색만 달라요(3·6·9·12부 사진 비교).
- 길목 27곳은 테마 10종의 되풀이. 길목 8(바위 고개)과 길목 20(별빛 계단)은 사실상 같은 그림.
- 퀘스트 55개 중 49개가 잡기(21)·모으기(28).

## 1. 마을 12곳 — 배치 틀 6가지 + 그 마을만의 장소 (✅ 2026-11-16 완료, 사진 `docs/마을_배치_12곳.png`)
저장과 맞게 지키는 것: 지워진 곳 8개(핵심 자리 1개 포함), 건물 문 좌표(`to`/`at`)는 건물을 옮기면 같이 옮김, 출구 방향, `wireEntries()`. 진행 봇(`bot.cjs`) 통과가 조건.

| 부 | 마을 | 지금 | 새 배치 틀 | 그 마을만의 장소(새로) | 사람들의 움직임 |

- 필요한 그림: 새 소품 약 18종(부두 판자·좌판·모루·분수·무대·깃발·파라솔·그물·볏단·떠 있는 책장·액자·묘비·제단 등), PixelLab `create_map_object` 로 **약 18~24회 생성**(64점). 바닥 타일은 지금 것 재사용.

- 길목마다 몬스터 3~5종이 되게 보강(지금 2종뿐인 r1·r2·r3·r4·r8·r11·r15·r18·r20). 새 몬스터는 만들지 않고 그 부에 어울리는 기존 몬스터를 배치.
- 장치는 **막히지 않게**: 못 풀어도 돌아가는 길이 있고, 진행 봇이 통과하도록 "장치 없이도 걸어갈 수 있는 길"을 둠. 가벼운 화면에서도 동작.
- 필요한 그림: 장치 소품 약 10종(끊긴 다리·통나무·등불 기둥·얼음 바닥·바람 표시·뗏목·톱니 발판·구름 발판·색 꽃·사라지는 바닥), **약 10~14회 생성**.

## 3. 퀘스트 — 새 종류 6가지 (✅ 2026-11-15 완료, `src/29-quests.js`, 결과는 `docs/작업_프롬프트2_고치기.md` 'O 3단계')
| 새 종류 | 내용 | 배움과의 연결 |
|---|---|---|
| 호위 | 마을 사람을 길목 끝까지 데려다주기(같이 걸음, 몬스터가 다가오면 멈춤) | - |
| 수수께끼 | 그 부 단원 개념으로 답하는 선택지("내 나이의 2배에서 3을 빼면 13") | 단원 개념 |
| 시간 안 배달 | 따뜻할 때 전하기(막대가 줄어듦, 늦어도 벌 없이 보상만 조금 적음) | - |
| 도감 사진 | 그 길목 몬스터 3종을 만나 도감에 담기 | - |
| 고민 듣기 | 이야기 듣고 선택지 고르기, 고른 것에 따라 다른 답례·대사 | 읽기 |
| **가르쳐 주기** | NPC 가 틀리게 푼 풀이를 보여 주고 **틀린 줄**을 찾기 | 오개념 찾기(배움 효과 큼) |

- 지금 잡기·모으기 49개 가운데 **약 24개를 새 종류로 바꿈**(부마다 2개씩). 기존 저장의 진행 중 퀘스트는 그대로 끝낼 수 있게 id 를 유지.
- 서브 퀘스트 12개에는 2~3번 이어지는 작은 사연(예: 2부 등대지기의 잃어버린 편지 → 편지의 주인 → 답장 전하기).

## 4. 장면 그림
- `prototypes/1_옆에서보는_버전…html` 의 풍경 그림 12장은 **옛 벡터풍**이라 지금 도트 화풍과 맞지 않아요. 그대로 쓰지 않는 것을 권해요.
- 대신 부 시작·끝에 **지금 게임 그림으로 만든 장면 컷**(그 마을의 랜드마크 + 인물 2~3명을 크게 확대한 한 장면, 대화창 위)을 엔진으로 그려요 → 그림을 새로 받지 않아도 돼요.
- PixelLab 으로 받는다면: 부마다 1장(320×180쯤) = **12~24회 생성**.
