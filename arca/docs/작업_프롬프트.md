## 프롬프트 A · 한 판만 더 (콤보·스킬·도감·보상·숫자 입력)

```
아르카 연대기(arca/)에 "한 판만 더" 장치를 넣어 줘. arca/docs/작업_프롬프트.md 의 [공통 규칙]을 먼저 읽고 따라.

[목표] 아이가 문제를 맞히는 것이 신나고, 모으고 싶은 것이 눈에 보이게.

[할 일]
1. 연속 정답 콤보
   - 지금 FLD.streak(src/09-field.js)는 세기만 하고 화면에 안 보여. 주인공 머리 위나 화면 가장자리에 "3연속!" 숫자를 보여 주고, 커질수록 크고 화려하게.
   - 3연속: 피해 +20%, 5연속: 필살기 자동 발동(직업 색 큰 이펙트, 피해 2배), 그 뒤에도 콤보는 이어져.
   - 틀리면 콤보가 끊기고 "아깝다! 5연속에서 끊겼어요"처럼 다시 하고 싶게 한 줄.
   - 최고 콤보 기록을 save 에 남기고 내 정보에 보여 줘.
2. 스킬을 진짜로 다르게
   - 지금 직업마다 스킬 이름은 12개인데 효과는 6종(hit2·hit3·ult·guard·heal·double)뿐이야(src/04-characters-and-data.js 의 SKE·EFF).
   - 직업 색이 살도록 효과를 늘려 줘. 예: 범위 공격(주변 몬스터 모두), 관통(일직선), 기절(몇 초 멈춤), 끌어당기기, 밀치기, 독(시간 피해), 보호막(하트 임시 +), 게이지 채우기, 다음 문제 보기 하나 지우기, 펫 합동 공격.
   - 기사=지키기·버티기, 전사=범위·연타, 마법사=상태 이상·원거리, 궁수=관통·치명타 느낌으로 나눠.
   - 스킬 설명 글이 옛 숫자("바로 피해 2")로 남아 있어. 지금 공격력 계산(공격력의 1.5배·2배·3배)에 맞게 고쳐.
   - 스킬 이름과 12부 이야기(docs/아르카연대기_전체줄거리_12부.pdf)의 스킬 표가 어긋나지 않게.
3. 도감 3종 (마이룸 패널의 새 탭 "도감")
   - 몬스터 도감: 만난 몬스터의 그림·이름·물리친 수·그 몬스터에게 맞힌 문제 수. 못 만난 칸은 그림자.
   - 아이템 도감: 얻어 본 장비(등급별 표시). 지문 도감: 읽은 지문 제목.
   - "23 / 32"처럼 빈칸이 보이게 하고, 한 종류를 다 채우면 칭호(이름 옆에 붙는 말)와 작은 보상.
4. 다시 만난 문제 보상 키우기 (src/15-play.js)
   - 틀렸던 문제를 다시 만나 맞히면 지금은 알림 한 줄뿐이야. 별이 터지는 연출 + 별빛 가루 보너스 + "기억을 되찾았어요!" 를 넣어.
   - 오답 노트에서 지워진 문제 수를 "되찾은 기억 n개"로 세어 내 정보와 도감에 보여 줘.
5. 숫자 직접 넣기
   - 길목 단계(tier) 4~5와 보스의 3단계에서는 보기 3개 대신 숫자를 직접 넣는 문제를 섞어(화면 숫자 키패드 + 키보드). 문제 은행(QUIZ.makeQuestion 의 responseMode:"short")을 써.
   - 분수·글 답처럼 숫자로 못 넣는 답은 지금처럼 보기로.

[확인] 콤보 3·5연속, 스킬 효과 종류별 1번씩, 도감 채우기, 다시 만난 문제 보상, 숫자 입력 정답·오답을 검사 스크립트로 확인하고 화면 사진을 보여 줘.
```

## 프롬프트 B · 약점 숫자 전투 (완료)

```
아르카 연대기(arca/)의 전투를 "문제 상자"에서 "약점 숫자 맞히기"로 바꾸는 작업이야. arca/docs/작업_프롬프트.md 의 [공통 규칙]을 먼저 읽고 따라.
이건 CLAUDE.md 의 확정된 설계(길 위 전투)를 바꾸는 일이니, 코드를 쓰기 전에 설계안을 먼저 나에게 보여 주고 확인받아.

[왜] 지금은 공격이 닿으면 화면이 멈추고 "계산해 보세요. 3 + 3 × 5" 상자가 떠. 게임 상황과 문제가 상관없어서 시험지 같아. 수학이 통행료가 아니라 공격 방법 자체가 되게 하고 싶어.

[핵심 아이디어]
- 몬스터 머리 위에 "문제 말풍선"이 떠 있어(예: "6 × 7", "12의 약수", "3/4보다 큰 것").
- 내 공격 버튼(또는 숫자 구슬 3개)에 답 후보가 실려 있어. 맞는 숫자로 공격하면 약점을 찔러 큰 피해 + 콤보, 틀린 숫자면 튕겨 나가고 피해 절반 + 풀이를 잠깐 보여 줘.
- 화면이 멈추지 않아야 해. 다만 초등학생이 서두르다 찍지 않도록, 말풍선이 뜬 몬스터는 천천히 다가오거나 잠깐 멈춰 서게 해.
- 몬스터 종류마다 문제 유형을 묶어(src/12-monsters.js 의 몬스터, src/15-play.js 의 MOVE): 예) 태엽 병정=곱셈구구, 잉크 얼룩이=글 문제, 금화 들쥐=나눗셈, 망각 유령=틀렸던 문제.
- 문제는 지금처럼 선생님 설정의 학년·부(단원)에 맞춰 문제 은행(../quiz-bank.js, 읽기만)에서 가져와.

[지켜야 할 것]
- 틀려도 벌보다 다시 도전: 틀리면 풀이를 보여 주고 같은 몬스터가 비슷한 문제를 다시 들고 와.
- 직업별 공부 도움(기사·전사·마법사·궁수 패시브), 오답 노트, 다시 만나기, 치명타·막기, 콤보(프롬프트 A)가 그대로 이어지게.
- 휴대폰·태블릿에서 답 버튼이 크고 누르기 쉽게. 키보드는 1·2·3.
- 글이 긴 문제(지문·글 문제)는 말풍선에 안 들어가니 그때만 지금 같은 상자를 써도 돼.
- 접근성: 글자 크게·읽어 주기 설정이 말풍선에도 적용되게.
- 옛 방식으로 돌아가는 설정(선생님 설정에 "전투 방식: 약점 숫자 / 문제 상자")을 남겨.

[순서]
1) 설계안(화면 그림 설명, 조작, 몬스터-유형 표, 바뀌는 파일)을 먼저 보여 줘 → 내 확인
2) 1부 길목 한 곳에서만 먼저 만들어 플레이 링크로 보여 줘 → 내 확인
3) 전체 길목과 보스에 적용, 균형(econ.cjs) 다시 맞추기

[확인] 정답·오답·콤보·쓰러짐·보스·휴대폰 화면을 검사하고, 한 판(몬스터 5마리)에 걸리는 시간이 지금보다 길어지지 않았는지 알려 줘.
```

## 프롬프트 D · 학습 기록 + 선생님 보고서 (완료)

```
아르카 연대기(arca/)에 학습 기록과 선생님 보고서를 넣어 줘. arca/docs/작업_프롬프트.md 의 [공통 규칙]을 먼저 읽고 따라.

[왜] 전국 배포와 시범 운영을 하려면 선생님이 "누가 어느 단원을 얼마나 맞히는지"를 볼 수 있어야 해. 나중에 Pesk(서버)에 연결할 때 이 기록을 그대로 보내려고 해.

[할 일]
1. 기록 모으기 (새 파일, 순수 데이터 구조)
   - 문제를 풀 때마다: 날짜, 부, 단원 이름, 유형(수학/영어/지문), 맞음·틀림, 걸린 시간(초), 다시 만난 문제인지.
   - 저장 용량이 커지지 않게: 최근 300문제는 낱개로, 그 이전은 단원별·날짜별 합계로 접어.
   - 개인정보는 넣지 마(이름 대신 게임 속 별명만).
   - 저장 위치는 지금 save 와 따로(localStorage "arca-log"), 구조에 버전 번호를 붙여.
2. 선생님 보고서 화면 (게임 위쪽 "선생님 설정" 옆 "학습 보고서" 버튼)
   - 요약: 푼 문제 수, 정답률, 공부한 날 수, 최근 7일 막대.
   - 단원별 표: 문제 수·정답률·평균 시간, 정답률이 낮은 단원은 눈에 띄게.
   - 자주 틀리는 문제 5개(문제 글과 정답), 되찾은 기억(다시 맞힌 문제) 수.
   - 진도: 지금 몇 부, 되살린 마을 수, 레벨.
   - 색만으로 구분하지 말고 글자·기호도 같이.
```
