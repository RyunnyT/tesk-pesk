# 설계안 · 약점 구슬 전투 (프롬프트 B, 2026-11-15) — 선생님 확인 전

## 왜 원래 안(몬스터 머리 위 말풍선)을 바꾸나
5학년 12단원 문제를 60개씩 뽑아 보니, 말풍선(14자 안)에 들어가는 짧은 식은 **4단원뿐**:
혼합 계산(77%), 분수의 덧셈과 뺄셈, 분수의 곱셈, 소수의 곱셈(100%).
나머지 8단원(약수와 배수, 규칙과 대응, 약분과 통분, 다각형의 넓이, 어림, 합동과 대칭, 직육면체, 평균과 가능성)은 20~70자 문장 문제.
→ 말풍선만 쓰면 1년의 2/3가 예전 상자로 돌아간다. 그래서 **"문제는 화면 아래 띠, 답은 내 주위 구슬"**로 바꾼다.

## 한 판의 흐름
1. 몬스터에게 다가가 **Q(공격)** → 그 몬스터를 **조준**(빨간 표시). 조준된 몬스터는 **멈칫**(움직이지도 부딪히지도 않음). 다른 몬스터는 절반 속도.
2. 문제는 **짧으면 몬스터 머리 위 말풍선**, 길면 **화면 아래 반투명 '문제 띠'**(두 줄까지). **게임은 멈추지 않는다.** 시간 제한 없음.
3. 주인공 둘레에 **답 구슬 3개**(숫자·분수 글자)가 돈다. **1·2·3**(태블릿은 화면 오른쪽 큰 구슬 버튼)으로 던진다.
4. 구슬이 날아가 맞으면
   - 정답: **약점 폭발**(큰 별빛 터짐, 피해 그대로, 콤보 +1)
   - 오답: **튕겨 나감**(피해 절반, 콤보 끊김) + 문제 띠가 **풀이**로 바뀌어 3초. 같은 몬스터가 비슷한 문제를 다시 들고 온다.
5. 몬스터가 쓰러질 때까지 2~4번. 끝나면 조준이 풀리고 다시 걷는다.

## 몬스터가 부딪혀 올 때(피하기)
지금처럼 "피하기 문제"는 남기되 같은 구슬 방식으로: 부딪힌 몬스터가 조준되고, 맞히면 **피하며 반격**(작은 피해), 틀리면 하트 감소.

## 몬스터 성격 = 문제 "모양" (단원은 늘 그 부의 단원, 교육과정 순서 유지)
| 몬스터 | 문제 모양 |
|---|---|
| 대부분 | 그 부 단원의 보통 문제 |
| 잉크 얼룩이 | 같은 단원을 **글 문제**로 |
| 태엽 병정·톱니 벌레 | **숫자 직접 넣기**(구슬 대신 숫자 판) |
| 금화 들쥐 | 도망 다니고, 잡으면 **짧은 문제**(빠른 판단) |
| 망각 유령·지우개 덩어리 | **틀렸던 문제**(다시 만나기) |
| 문지기·보스 | 단계마다 다른 모양, 마지막 단계는 숫자 직접 |

## 그대로 이어지는 것
직업별 공부 도움(기사 막기·전사 연속·마법사 다시 생각·궁수 보기 지우기), 오답 노트, 다시 만나기, 치명타·막기, 콤보·필살기, 스킬(범위·관통 등), 힌트 스킬, 숫자 판, 글자 크게·읽어 주기(조준할 때 문제를 읽어 줌), 흔들림 끄기.

## 조작
- 키보드: 방향키 이동 · Q 조준/공격 · 1·2·3 구슬 던지기 · Esc 조준 풀기(도망)
- 태블릿: 왼쪽 방향 버튼 · 오른쪽 아래 **큰 구슬 버튼 3개**(조준 중에만, 공격 버튼 자리)
- 화면 겹침: 문제 띠는 아래쪽 대화창 자리(대화창이 열리면 띠는 위로), 상단 상태·퀘스트와 겹치지 않게.
