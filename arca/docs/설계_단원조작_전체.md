# 설계안 · 모든 단원 미니 조작 (프롬프트 I, 2026-11-15) — 선생님이 고르신 것부터

문제 은행(`quiz-bank.js`)의 3~6학년 단원 이름을 종류로 묶고, 종류마다 조작 하나씩 제안해요. **C 의 3종**(물약 조합·주문 순서·저울 눈금)이 먼저 들어간 뒤, 고르신 것부터 **한 번에 2종씩** 만들어요.
