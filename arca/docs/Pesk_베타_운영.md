# 아르카 연대기 — Pesk 안 베타 체험판 운영 안내 (2026-11-17)

Pesk 학생 앱 안에 「🧪 아르카(베타)」 메뉴로 넣었습니다. **⚔️ 모험과는 따로**라서 모험의 코인·경험치·레이팅·모험 기록에는 아무 영향이 없습니다.

## 1. 배포하기 (선생님 컴퓨터에서 한 번)
1. 저장소를 최신으로 받습니다(`arca-chronicles` 브랜치).
2. 평소처럼 `deploy-cloudflare.bat` 을 실행합니다.
   - 새로 생긴 단계 **[4.5/6]** 이 `arca\tools\build_single.py` 로 게임을 파일 하나로 묶어 `arca.html`(게임)·`arca-teacher.html`(학습 기록 모아 보기)로 함께 올립니다.
   - **python 이 필요합니다.** 없으면 "[알림] 아르카 파일을 만들지 못했어요" 가 뜨고, 나머지 Pesk 는 그대로 배포됩니다.
3. 배포가 끝나면 `https://(Pesk 주소)/arca` 로 게임이 열리는지 확인합니다.

## 2. 우리 반만 켜기
- 교사 대시보드 → **📱 학생 Pesk 메뉴 켜기 · 끄기** → 맨 아래 **🧪 아르카 연대기 (베타 체험판)** 를 켭니다.
- 처음에는 꺼져 있습니다. 켠 학급에만 학생 메뉴에 「🧪 아르카 베타」(휴대폰은 「더보기」 안)가 생기고, 끄면 바로 사라집니다(열려 있던 창도 닫힘).
- 같은 칸의 링크: **선생님이 먼저 해 보기**(선생님용 저장 칸), **학습 기록 모아 보기**.
- 「✍️ 글쓰기 먼저」가 켜져 있으면 아르카도 글을 낸 뒤 열립니다.

## 3. 학생 화면
- 메뉴를 누르면 게임이 전체 화면 창으로 열리고, 위에 「✕ Pesk 로 돌아가기」 단추가 있습니다(닫을 때 한 번 더 저장).
- **학년**: 교사 대시보드 모험 학습의 「📚 출제 범위」 학년을 그대로 씁니다(학생이 바꿀 수 없음). 「선생님 설정」·「처음부터」 단추는 숨깁니다.
- **저장(2026-11-18부터 서버 저장)**: 진행과 학습 기록은 **학생마다 Pesk 서버**에 저장됩니다. 어느 기기에서든 Pesk 로 로그인해 열면 이어서 합니다.
  - 기기에도 함께 저장해서(학생마다 칸이 따로) 인터넷이 끊겨도 계속 놀 수 있고, 다시 연결되면 올라갑니다.
  - 60초마다·창을 숨길 때·「✕ Pesk 로 돌아가기」를 누를 때 **바뀐 것만** 올립니다. 화면 위에 「☁️ 저장됨 12:31」처럼 보입니다.
  - 두 기기에서 번갈아 하면 열 때 **더 많이 진행한 쪽**(맞힌 문제 수)으로 이어 하고 한 줄 알려 줍니다. 두 기기를 동시에 켜 놓고 하면 "다른 기기에서 이어 했어요"가 떠서 고르게 합니다.
  - **학습 기록은 1년 보관**합니다(서버에는 365일이 지난 기록을 빼고 올림).

## 4. 학습 기록 보기
- 교사 대시보드 → 「📱 학생 Pesk 메뉴」의 아르카 칸 → **📊 아르카 학습 기록 보기**.
  - 학생별: 번호·**실명**(명렬표)·게임 별명·진도(부·레벨)·푼 문제·정답률·최근 날짜·약한 단원(▼)·자주 틀린 문제
  - 반 전체: 단원별 정답률(▼ = 10문제 이상인데 60% 아래)
  - **CSV 내려받기**
- 서버에는 이름 없이 번호만 저장하고, 실명은 선생님 화면에서만 명렬표로 붙입니다.
- **🗑 아르카 기록 지우기**: 우리 반 아르카 진행·기록을 서버에서 모두 지웁니다(확인 두 번). 「학급 자료 모두 지우기」에도 아르카가 들어 있습니다.
- (예전 방식) 학생 기기의 「학습 보고서 → 내보내기」 + `arca-teacher.html` 도 그대로 됩니다.

## 4-1. 배포할 때 꼭: 보안 규칙 먼저
1. `firestore.rules` 에 아르카 블록이 들어 있습니다. **먼저** `node tests/arca.rules.remote.cjs`(firebase login 필요)로 규칙 검사 → 모두 통과 확인.
2. `firebase deploy --only firestore:rules` 로 규칙 배포.
3. 그다음 `deploy-cloudflare.bat` 으로 Pesk 배포.
   - 순서가 바뀌어도 잃는 것은 없습니다(서버 쓰기만 거절되고 기기 저장은 남음). 하지만 규칙을 먼저 해야 바로 서버 저장이 됩니다.

## 4-2. 가정 안내문에 넣을 한 줄(예시)
> 수학 학습 게임 「아르카 연대기」(Pesk 안 체험판)를 하면, 푼 문제·정답 여부·걸린 시간이 Pesk 에 학생 번호로 저장되어 담임 선생님이 학습 지도에 씁니다. 이름은 저장하지 않으며, 기록은 1년 보관 뒤 지웁니다.

## 바뀐 파일
- `pesk.html`: `openArca()`·`closeArca()`, 탭·더보기 단추, `peskFeatures.arcaBeta`(기본 꺼짐).
- `tesk_teacher_v2.html`: 메뉴 켜기·끄기 칸에 아르카(베타) 스위치(`pesk-features.arcaBeta`).
- `deploy-cloudflare.bat`: [4.5/6] 아르카 묶기·복사.
- `arca/src/00-pesk-beta.js`: `?p=` 학생 칸(저장 이름 뒤 `@p`), `?g=` 학년, 체험판 화면.
- `shared/pesk-arca-store.js`: 서버 저장(학생별 `arca-save`·`arca-log`, 고르기·올리기·두 기기·1년 보관·요약·지우기).
- `firestore.rules`: 아르카 블록(전환 학급은 자기 번호만, rev +1, 지우기는 선생님). `shared/class-erase.js`: 학급 지우기에 아르카.
- 검사: `arca/tools/check/pesk.cjs`(가짜 서버로 이어 하기·두 기기·끊김·교사 표), `tests/arca-store.test.cjs`, `tests/arca.rules.remote.cjs`(선생님 PC).
