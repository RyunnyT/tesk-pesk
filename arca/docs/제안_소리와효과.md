## 파일 하나 빌드에 넣을지
- 효과음·스킬 그림(약 1MB)은 **넣는다**(지금처럼 파일 하나로 돌아가게).
- 배경음악(약 7MB)은 넣으면 파일 하나가 6MB → 13MB 가 되고 첫 화면이 느려진다. **따로 두기(`dist/music/`)를 권함**: 음악 파일이 없으면 조용히 음악 없이 돈다. 플레이 링크(아티팩트)에는 음악 파일을 함께 올릴 수 있다.
- 교실용: 소리는 학생이 화면을 누른 뒤에만, 기본 소리 크기 작게(음악 30%, 효과음 50%), 메뉴에서 음악·효과음 따로 크기·끄기.
