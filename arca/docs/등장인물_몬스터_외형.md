## 1. 주인공 (직업별)

플레이어는 이름만 정하고, 직업을 고르면 겉모습이 바뀝니다.

| 직업 | 머리 | 옷 | 들고 있는 것 | 느낌 |
|---|---|---|---|---|
| 직업 전(견습생) | 갈색 짧은 머리 | 베이지 상의 + 갈색 줄, 회색 바지 | 없음 | 평범한 마을 아이 |
| 기사 | 은빛 투구 `#b8c0cc` + 빨간 깃털 (머리카락 안 보임) | 파란 상의 `#378ADD` + 노란 줄, 회색 팔(사슬 갑옷) | 왼손 파란 방패(노란 무늬), 오른손 검 | 든든하고 반듯함 |
| 전사 | 적갈색 머리 + 빨간 머리띠 | 갈색 상의, 맨팔, 진갈색 바지·부츠 | 도끼 | 힘이 세고 씩씩함 |
| 마법사 | 갈색 머리, 보라 마법사 모자 + 노란 띠 | 보라 로브 + 노란 줄 | 나무 지팡이 + 보석 | 차분하고 똑똑함 |
| 궁수 | 초록 두건 | 초록 상의, 갈색 바지·부츠, 등에 화살통 | 처음엔 단검 → 성장하면 활 | 날렵함 |

- **검·무기 색**은 장비 단계에 따라 바뀝니다(나무 → 쇠 → 은 → 금빛).
- 공격할 때 무기를 휘두르는 짧은 동작, 스킬은 직업 색(기사 파랑, 전사 빨강, 마법사 보라, 궁수 초록) 빛이 납니다.

## 2. 펫과 별고양이

### 펫 5종 (처음에 하나 고름)
| 펫 | 겉모습 |
|---|---|
| 강아지 | 황토색 몸, 아래로 처진 귀, 짧은 꼬리 |
| 고양이 | 회색 몸, 위로 세운 꼬리, 뾰족한 귀 |
| 여우 | 주황 몸, 꼬리 끝이 흰색 |
| 토끼 | 흰 몸, 긴 귀, 귀 안쪽 분홍 |
| 병아리 | 노란 몸, 주황 부리·발 |

### 펫 성장 4단계 (모든 펫 공통)
1. 기본 모습
2. **빨간 목걸이 + 금방울**
3. 목걸이 + **이마에 별 표식**, 몸 주변 반짝임
4. 목걸이 + 별 표식 + **등에 작은 별날개**

- 비밀: 별고양이 12마리를 모두 찾으면 펫 몸에 **별무늬**가 생깁니다.

### 별고양이 (숨은 수집 대상, 12마리)
- 크림색 작은 고양이, **이마에 노란 별**, 분홍 코. 앉아 있다가 가까이 가면 반짝입니다.

## 6. 그림 새로 그릴 때 메모

1. **녹스 계열 색은 지키기**: 창백한 보랏빛 피부 + 분홍 눈 + 남색 두건. 그림자 견습생은 모두 **회색 두건**이 공통 표시.
2. **부엉이 두 마리 구분**: 모모 = 갈색 + 보라 넥타이, 얼음 부엉이 = 하늘색.
3. **꼬마 인물**(토토·소라·제이·도토·리토·아리엔·루크)은 키를 2~3칸 작게.
4. **몬스터 분위기**: 1학기(1~6부)는 안개·바다·숲·기계, 2학기(7~12부)는 들판·꿈·눈·지워짐(하얀색) 쪽으로 갈수록 색이 옅어짐 → "세상이 지워진다"는 이야기와 맞춤.
5. 인물 그림을 바꿀 때는 `src/04-characters-and-data.js`의 인물 설정(`D`)만 바꾸면 모든 지도에 같이 반영됩니다. 몬스터는 `MON[이름].dr` 그림 함수, 새 몬스터는 `src/12-monsters.js`.
