# 아르카 연대기 — Pesk 안 베타 체험판 운영 안내 (2026-11-17)

Pesk 학생 앱 안에 「🧪 아르카(베타)」 메뉴로 넣었습니다. **⚔️ 모험과는 따로**라서 모험의 코인·경험치·레이팅·모험 기록에는 아무 영향이 없습니다.

## 1. 배포하기 (선생님 컴퓨터에서 한 번)
1. 저장소를 최신으로 받습니다(`arca-chronicles` 브랜치).
2. 평소처럼 `deploy-cloudflare.bat` 을 실행합니다.
   - 새로 생긴 단계 **[4.5/6]** 이 `arca\tools\build_single.py` 로 게임을 파일 하나로 묶어 `arca.html`(게임)·`arca-teacher.html`(학습 기록 모아 보기)로 함께 올립니다.
   - **python 이 필요합니다.** 없으면 "[알림] 아르카 파일을 만들지 못했어요" 가 뜨고, 나머지 Pesk 는 그대로 배포됩니다.
3. 배포가 끝나면 `https://(Pesk 주소)/arca` 로 게임이 열리는지 확인합니다.

## 2. 우리 반만 켜기
- 교사 대시보드 → **📱 학생 Pesk 메뉴 켜기 · 끄기** → 맨 아래 **🧪 아르카 연대기 (베타 체험판)** 를 켭니다.
- 처음에는 꺼져 있습니다. 켠 학급에만 학생 메뉴에 「🧪 아르카 베타」(휴대폰은 「더보기」 안)가 생기고, 끄면 바로 사라집니다(열려 있던 창도 닫힘).
- 같은 칸의 링크: **선생님이 먼저 해 보기**(선생님용 저장 칸), **학습 기록 모아 보기**.
- 「✍️ 글쓰기 먼저」가 켜져 있으면 아르카도 글을 낸 뒤 열립니다.

## 3. 학생 화면
- 메뉴를 누르면 게임이 전체 화면 창으로 열리고, 위에 「✕ Pesk 로 돌아가기」 단추가 있습니다(닫을 때 한 번 더 저장).
- **학년**: 🎓 모험 학습 설정의 학년을 그대로 씁니다(학생이 바꿀 수 없음). 「선생님 설정」·「처음부터」 단추는 숨깁니다.
- **저장**: 진행과 학습 기록은 **학생이 쓰는 그 기기에만** 저장됩니다. 저장 이름에 「학급 코드-번호」를 붙여서, 학교 태블릿을 여러 학생이 같이 써도 섞이지 않습니다.
  - 학생이 기기를 바꾸면 처음부터 시작합니다(서버 저장은 체험 뒤에 결정).
  - 브라우저 기록·사이트 데이터를 지우면 진행도 지워집니다.

## 4. 학습 기록 보기
- 학생 기기에서: 게임 위쪽 「학습 보고서」 → 내보내기(JSON).
- 선생님: 「학습 기록 모아 보기」(arca-teacher.html)에 학생 JSON 을 끌어다 놓으면 학생별 정답률·단원별 학급 평균이 나옵니다.

## 5. 체험 뒤에 정할 것
- 서버(Firestore)에 학생별 저장: 기기를 바꿔도 이어 하기, 교사 대시보드에서 바로 기록 보기(보안 규칙 배포 필요).
- ⚔️ 모험과 연결(코인·레이팅 등)할지.

## 바뀐 파일
- `pesk.html`: `openArca()`·`closeArca()`, 탭·더보기 단추, `peskFeatures.arcaBeta`(기본 꺼짐).
- `tesk_teacher_v2.html`: 메뉴 켜기·끄기 칸에 아르카(베타) 스위치(`pesk-features.arcaBeta`).
- `deploy-cloudflare.bat`: [4.5/6] 아르카 묶기·복사.
- `arca/src/00-pesk-beta.js`: `?p=` 학생 칸(저장 이름 뒤 `@p`), `?g=` 학년, 체험판 화면.
- 검사: `arca/tools/check/pesk.cjs`.
