# 그림 업그레이드 기록

아르카 연대기의 그림을 "2000년대 도트 게임" 느낌에서 "요즘 2등신 캐주얼 RPG" 느낌으로 바꾸는 작업의 기록이다.
결정한 것, 만든 방법, 다음에 할 일을 날짜순으로 적는다. 그림 작업을 이어서 할 때는 이 문서를 먼저 읽는다.

## 1. 견본 (2026-11-13)

### 왜 시작했나
- 선생님 의견: 지금 그림이 너무 2000년대 같다. 메이플스토리 같은 느낌이면 좋겠다.
- 지금 그림이 옛날 게임처럼 보이는 까닭
  - 게임 화면이 320×180 칸이고 사람 한 명이 16×20 칸쯤이라 눈·표정·머리카락을 그릴 자리가 없다.
  - 네모 조각(`P()` 함수)만 써서 테두리 선·곡선·명암이 없다.
  - 색이 진하고 단순하다.

### 정한 것
- **방법 A**: 위에서 내려다보는 방식(탑다운)과 지금까지 만든 12부 지도·이야기·퀘스트는 그대로 두고 **그림만** 바꾼다.
  (방법 B = 옆에서 보는 방식으로 바꾸기는 지도 48개와 이동·전투를 다시 만들어야 해서 하지 않기로 했다.)
- 전체에 적용하기 전에 **견본 한 장면**을 먼저 만들어 선생님께 확인받는다.
- 메이플스토리의 캐릭터·몬스터·그림을 그대로 따라 그리지 않는다. 분위기(2등신, 테두리 선, 밝은 색, 옷 입히기)만 참고한 우리 그림으로 만든다.
- 외부 그림 파일을 쓰지 않고 지금처럼 **코드로 그린다**. 출처 표기·저작권 걱정이 없고 파일 하나로 묶는 방식도 유지된다.

견본에 들어 있는 것: 직업 4가지(기사·전사·마법사·궁수), 표정 3가지(웃음·놀람·울상), 펫(여우), 마을 사람(마르타 할머니·카이·모모),
몬스터 2종(안개 슬라임·안개 해파리), 배경(풀밭·흙길·연못·울타리·나무·집·표지판), 지워진 곳, 이름표·말풍선·체력 막대·피해 숫자.

### 그리는 방법

**1) 화면 크기를 3배로**
- 320×180 → **960×540**. 사람 키가 20칸쯤에서 **82칸쯤**으로 커져 얼굴을 그릴 수 있다.

**2) 네모 대신 길(path)로 그린다**
- 캔버스의 `ellipse`, `roundRect`, `bezierCurveTo`, `quadraticCurveTo` 로 둥근 모양을 만든다.
- 모든 그림은 `shape(c, 채울 색, 길, 테두리 굵기)` 함수 하나로 그린다: 길을 만들고 → 색을 채우고 → 테두리를 두른다.
- 테두리 색 `OL = #4a3426`(진한 갈색), 굵기 2.5, 모서리는 둥글게(`lineJoin = round`). 검정보다 부드럽게 보인다.
- 명암은 `soft()` 로 반투명 타원을 얹는다: 머리·옷·몬스터 위쪽에 흰 윤기, 아래쪽에 조금 어두운 색. 그러데이션은 쓰지 않는다.
- 볼터치(분홍 반투명 타원)와 눈 속 흰 점이 귀여운 느낌을 만드는 데 효과가 크다.

**3) 사람은 2등신 + 옷 입히기**
- 함수 `chibi(c, x, y, 설정, 시간)` 하나로 모든 사람을 그린다. 기준점은 발바닥 가운데.
- 비율(키 82): 다리 14 · 몸 26 · 머리 42. 머리가 몸보다 크다.
- 겹치는 순서: 그림자 → 망토·뒷머리 → 뒷팔(+검·도끼·지팡이) → 다리 → 몸 → 머리 → 앞머리 → 얼굴 → 모자 → 앞팔(+활).
- 설정값으로 겉모습을 바꾼다 (`CAST` 표):
  `skin` 피부색 · `hair` 머리색 · `hs` 머리 모양(기본/spiky/long/pony/bun) · `top`/`bot`/`sleeve`/`trim` 옷 색 · `robe` 긴 옷 · `apron` 앞치마 ·
  `cape` 망토 · `chest` 가슴 갑옷 · `hat` 모자(helm/band/witch/cap) · `wp` 무기(sword/axe/staff/bow/bread) · `face` 표정(기본/wow/sad) · `s` 크기 · `dir` 방향.
- 새 인물을 만들 때는 설정 한 줄만 쓰면 된다. 장비를 바꾸면 겉모습이 바뀌는 것도 같은 방식으로 된다.

**4) 방향은 "오른쪽 3/4" 한 가지만 그리고 뒤집는다**
- 얼굴을 오른쪽으로 살짝 돌린 모습 하나만 그린다(오른쪽 눈을 조금 좁게, 입을 오른쪽으로).
- 왼쪽을 볼 때는 통째로 좌우를 뒤집는다(`dir = -1`). 위·아래로 걸을 때는 마지막에 보던 쪽을 유지한다.
- 이렇게 하면 앞·뒤·옆 그림을 따로 그릴 필요가 없고, 예전의 "주인공은 정면, 펫은 옆모습" 문제가 사라진다.

**5) 움직임은 그림을 더 그리지 않고 수식으로**
- 걷기: `sin(시간)` 으로 두 다리를 앞뒤로, 두 팔을 반대로 흔들고, 몸을 위로 살짝 튀긴다.
- 서 있기: 느린 `sin` 으로 숨 쉬듯 1칸쯤 오르내린다. 사람마다 박자(`ph`)를 달리해 따로 움직이게 한다.
- 눈 깜빡임: 4초에 한 번 눈 높이를 줄인다.
- 펫: 다리 네 개 번갈아, 꼬리 흔들기, 걸을 때 통통.
- 몬스터: 슬라임은 납작해졌다 늘어나며 튀고, 해파리는 둥둥 뜨며 다리가 물결친다. 맞는 순간 몸이 하얗게 번쩍인다.

**6) 배경**
- 배경은 숨은 캔버스(`paintBg`)에 한 번만 그려 두고 매 장면 그대로 붙인다.
- 풀밭: 바탕색 위에 밝고 어두운 반투명 타원 얼룩 46개 + 풀 포기(∨ 모양 선) + 꽃. 타일 경계가 보이지 않는다.
- 흙길: 같은 곡선을 굵기만 달리해 세 번 긋는다(테두리 → 가장자리 → 속). 모서리가 저절로 둥글어진다.
- 나무·집·표지판·울타리도 `shape()` 로 그리고 윤기와 그림자를 얹는다.
- 그리는 순서: 발 위치(y)가 위쪽인 것부터 그려서 아래쪽 것이 앞에 오게 한다.

**7) 지워진 곳**
- 흰 종이 모양 + 바깥으로 번지는 흰 빛(`shadowBlur`) + 움직이는 금색 점선 + 연필 밑그림 + 주위를 도는 별.

**8) 글자 표시**
- 이름표(반투명 어두운 둥근 상자), 말풍선(꼬리 달린 흰 상자), 체력 막대, 튀어 올랐다 사라지는 피해 숫자.

### 만들면서 고친 것
- 무기를 앞손에 들렸더니 얼굴을 가렸다 → 검·도끼·지팡이는 **뒷손**에 들려 머리 뒤로 비스듬히 나오게 했다. 활만 앞손에 든다.
- 기사 투구의 띠가 눈을 덮었다 → 띠와 투구를 위로 올렸다.
- 표지판이 사람과 겹쳤다 → 자리를 옮기고, 그리는 순서 값을 발 위치에 맞췄다.

### 확인한 것과 못 한 것
- 확인: 브라우저(크로미움)에서 견본을 열어 오류 없이 그려지고 움직이는 것. 화면을 찍어 눈으로 확인.
- 못 함: 학교 기기·휴대폰에서의 속도. 견본은 한 화면에 사람 4명·몬스터 2마리뿐이라, 실제 게임(큰 지도, 몬스터 여러 마리)에서는 아래 "속도" 대책이 필요하다.

## 2. 전체 적용 계획 (선생님 확인 뒤 시작)

1. **화면 크기**: `src/01-core.js` 의 캔버스를 320×180 → 960×540 으로, 타일 16칸 → 48칸. 좌표를 쓰는 곳(충돌, 카메라, 미니맵)은 타일 단위라 대부분 그대로 쓸 수 있는지 먼저 확인한다.
2. **사람**: `person()` 을 `chibi()` 로 바꾸고, 인물 모양 표 `D` 의 값(`hair`, `ht`, `top`, `robe` …)을 새 설정으로 옮긴다. 인물 약 50명.
3. **펫**: 강아지·고양이·여우를 새로 그리고 성장 3단계를 만든다.
4. **몬스터**: 19종을 새로 그린다. 보스는 2배 크기.
5. **지형·건물**: `ground()`, `objDraw()`, `bldDraw()`, 랜드마크 `LMD` 를 새 방식으로. 지형 색 `TH` 는 밝은 색으로 다시 정한다.
6. **지워진 곳·이펙트·글자 표시**: 견본의 것을 옮긴다.
7. **속도**: 사람·몬스터를 매번 길로 그리면 느릴 수 있다. 움직임 장면(프레임)마다 작은 숨은 캔버스에 한 번 그려 두고 `drawImage` 로 찍는다. 배경은 지금처럼 지도마다 한 번만 그린다.
8. **확인**: 부마다 화면을 찍어 비교하고, 휴대폰 크기에서도 본다.

한 번에 바꾸면 중간에 게임이 깨지므로, 1→2→5 순서로 "새 그림과 옛 그림이 섞여 있어도 돌아가는" 상태를 유지하며 진행한다.
