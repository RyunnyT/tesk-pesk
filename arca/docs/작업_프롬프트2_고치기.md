### 모든 프롬프트가 알아야 할 코드 사실
- 문제 한 개의 흐름: `fieldStrike`(09-field) → `askField(MI, title, cb)` → 안에서 `makeQ(dif)` → 답 단추 → `finish(ok)` → `cb(ok)` 에서 피해 계산(`let d = ok ? base : Math.ceil(base / 2)`).
- `askField` 는 여러 파일이 감싸요(안쪽부터): 09 원본 → 15-play(다시 만난 문제) → 17-fun(콤보·힌트) → 18-orb(구슬·문제 모양) → 19-log(학습 기록) → 21-loop(열쇠 조각) → 23 없음. 새로 감쌀 때는 **맨 바깥**(index.html 의 마지막 스크립트)에서.
- 지금 문제 정보는 `RQ.last = { q, a, ch[3], unit, ex, re?, short? }`. 문제 은행 원본은 `QUIZ.makeQuestion({grade, term, unitNos, tier, contextMode, responseMode})` → `{q, answer, options[4], explain, unit, inputKind…}` (`../quiz-bank.js`, **읽기만**).
- 틀린 문제: `noteWrong(Q)`(08-ui) → `save.wrong[]`, 다시 내기는 15-play 의 `makeQ` 감싸기(20%).
- 미니 조작 틀: `miniOpen(kind, {title, done})`, 문제 만들기 `mkOrder`·`mkPotion`·`mkScale`·`mkFactor`·`mkGear`, 계산 순서 `orderSteps(toks)`(22-mini).
- 단원: `unitName(mapPart())`, 종류 `miniKind(unitName)`.
- 검사: `tools/check/*.cjs`(fun·orb·log·loop·lite·mini·sound·econ·bot). 문제 상자를 직접 누르는 검사는 `studyCfg.battle = 'box'` 를 켜고 써요.
