## [공통 규칙] (모든 프롬프트에 적용)
1. 답과 문서는 한국어·쉬운 말. 먼저 `arca/CLAUDE.md` 를 읽는다(파일 지도·확정된 설계·주의점).
2. `arca/` 만 고친다. `../quiz-bank.js` 와 Pesk 파일은 읽기만. 운영 배포(Cloudflare) 금지.
3. 새 기능은 **새 파일 `src/35-…js` 부터 번호를 이어** 만들고 `index.html` 의 `<script>` 맨 끝(34-qinfo 뒤, 25-ui 앞)에 넣는다. 기존 함수는 감싸기(`const f0 = f; f = function(){…}`)로 덧붙인다. `const` 화살표 함수는 감쌀 수 없으니 필요하면 원본을 `let`/함수 선언으로 바꾼다.
4. 새 전역 이름은 짧은 머리글자를 붙여 겹치지 않게(예: `GROW_`, `RX`).
5. 저장 호환: `save` 에 새 필드를 넣을 때는 없을 때의 기본값을 꼭 처리한다(옛 저장으로 열어도 오류 없이). 새 필드는 되도록 `save.st.<이름>` 아래.
6. 벌·손해 주는 장치는 넣지 않는다(확정된 설계). "잃는 것"을 넣을 땐 아래 프롬프트에 적힌 범위만.
7. 그림을 외부(PixelLab 등)에서 받기 전에는 파일·출처·크기를 밝히고 허락받는다. 되도록 캔버스로 직접 그리거나 있는 그림을 쓴다.
8. 끝나면: ① 새 검사 `tools/check/<이름>.cjs` 작성(Playwright, 실패 시 exit 1) ② 전체 검사 실행 — `scene qinfo`는 dist 로 열므로 먼저 `python3 tools/build_single.py`, 그다음
   `for t in attack town route walk bot econ hearts quest wraps fun orb log perf lite loop mini sound learn ui lesson figq product scene qinfo; do node tools/check/$t.cjs; done` 모두 통과
   ③ `CLAUDE.md`(파일 지도·확정된 설계·콘텐츠 추가법)와 이 문서 끝에 "결과" 덧붙이기 ④ 교사 안내서(`docs/guide/make_guides.py` → `node docs/guide/print_pdf.cjs`)에 한 줄 ⑤ `python3 tools/build_single.py` ⑥ 플레이 링크 다시 올리기(dist 의 head·body 를 뽑아 아티팩트 https://claude.ai/artifact/DPD8pj1Yok2ewPa2QmQCfg 갱신) ⑦ 커밋 후 `arca-chronicles` 와 `claude/great-hypatia-e1hsyq` 두 브랜치에 푸시.
9. 선생님 확인이 필요한 결정(아래 "정해 주실 것")은 시작할 때 한 번에 묻고, 답이 없으면 "추천"으로 진행한다고 알린다.

## 프롬프트 R · RPG 깊이 (키우는 선택 · 상성 · 소모품 · 쓰러짐의 무게)


### 목표
"숫자만 오르는 게임"에서 "내가 골라서 키운 캐릭터"로. 학생이 **고르고, 궁리하고, 아끼는** 순간을 만든다. 벌은 주지 않는다.

### R-1. 레벨업 선택 (새 파일 `src/35-grow.js`)
- 레벨이 오를 때마다 **성장 점 1개**. 레벨업 직후(전투·대화가 끝난 뒤, `busy` 가 풀리면) 상자가 떠서 셋 중 하나를 고른다:
  - **힘** 공격력 +3 / **체력** 최대 하트 +1 / **별빛** 문제를 맞힐 때 별빛 게이지 +0.5(스킬을 더 자주)
  - 상자는 26-lesson 의 `lsOpenBox`·`lsHead` 를 쓴다(34-qinfo 참고). 큰 단추 3개 + 한 줄 설명 + 지금 수치.
- 저장: `save.st.grow = { pow: n, hp: n, star: n, free: n }`. 옛 저장은 `free = save.lv - 1 - (pow+hp+star)` 로 계산해 **지난 레벨만큼 점수를 돌려준다**(한꺼번에 고를 수 있게 "나중에" 단추 + 패널 「나」 탭에 "성장 점 n개 남음" 단추).
- 적용: `rpgAtk`(04c-rpg-save 73줄)·`maxHp`(05-player-state 46줄, `const` 화살표 → 감쌀 수 있게 바꾸기)·별빛 게이지 증가 지점(09-field `FLD.g` 를 올리는 곳)을 감싼다.
- **다시 고르기**: 마이룸 거울에서 금화(레벨 × 20)로 전부 되돌리기. 실수해도 손해가 없게.
- 균형: 기존 자동 성장(레벨당 공격 +2, 하트 +1)은 **그대로 두고** 성장 점은 덤이다. 덤 때문에 너무 쉬워지지 않게 `econ.cjs` 에 "힘만 찍은 경우" 열을 더해 일반 몬스터가 1.5번 아래로 쓰러지지 않는지 본다(넘으면 힘 +3 → +2).

### R-2. 스킬 강화 (같은 파일)
- 직업 스킬 12개(`SKL[job]`, 효과 `SKE`·`skMul` 17-fun) 각각 **강화 0~2단계**. 재료는 별빛 가루가 아니라 **스킬 조각**: 보스·문지기를 물리치면 1개, 도전의 탑 5층마다 1개, 현상금 몬스터 1개.
- 강화 1 = 피해 배수 +20%, 강화 2 = 효과 하나 추가(범위 +1칸 / 지속 +1초 / 게이지 소모 -1 중 스킬 종류에 맞는 것 — `SKE` 의 효과 이름별 표를 만들어 정한다).
- 화면: 패널 스킬 탭(마이룸 책장)에서 스킬을 누르면 "강화(조각 n개)" 단추. 저장 `save.st.skup = { [스킬번호]: 단계 }`, 조각 `save.st.skshard`.

### R-3. 몬스터 상성 (새 파일 `src/36-affinity.js`)
- 몬스터마다 **약점 하나**: `MON[k].weak` = `"fast"`(빨리 맞히면: 5초 안 정답 ×1.5) · `"combo"`(콤보 3 이상일 때 ×1.5) · `"skill"`(스킬 피해 ×1.5, 일반 공격 ×0.8) · `"first"`(첫 타 ×2, 그래서 체력이 가득일 때 스킬을 쓰면 좋음) · `"calm"`(틀린 직후 다음 정답 ×1.5 — 틀려도 만회).
  - 32종에 골고루 배정하는 표를 파일 맨 위에 둔다(같은 길목의 3종이 서로 다른 약점이 되게: `MAPS[id].mons` 를 훑어 검사).
- 표시: 조준했을 때 몬스터 머리 위 작은 표식(⚡빨리 · 🔥콤보 · ✦스킬 · ①첫 타 · ♻만회)과, 처음 만난 약점은 한 줄 안내(`toastLater`). 도감(17-fun `dexMon`)의 몬스터 칸에 약점 적기(만난 뒤에만).
- 적용 지점: 09-field `fieldStrike` 의 피해 계산(`let d = ok ? base : …` 뒤). 피해가 약점으로 늘었으면 `fxPop` "약점!".
- 배움과의 관계: 약점은 **맞혔을 때만** 덤이다. 빨리 찍기를 부추기지 않게 `"fast"` 는 24-learn 의 찍기 보호막(`m.shieldT`)이 켜져 있으면 무효.

### R-4. 소모품과 금화 쓸 곳 (새 파일 `src/37-items2.js`)
- 소모품 4종(가방에 종류별 최대 5개, `save.st.use = {heal:n, star:n, hint:n, ward:n}`):
  - **별빛 사과** 하트 3 회복 / **반짝 물약** 별빛 게이지 가득 / **힌트 두루마리** 다음 문제의 틀린 보기 하나 지움(17-fun 의 `FUN.hint` 재사용) / **수호 부적** 다음 덤비기 한 번 막음(31-attack `matkHit` 앞에서 소비)
- 얻는 곳: 마을 상점(16-rooms 의 상점 주인 → 14-rpg `PANEL.shop` 에 "물건" 줄 추가, 값은 부 × 8~15 금화), 보물 상자·열쇠 상자(21-loop)에서 가끔.
- 쓰는 법: PC 는 숫자키 5~8, 휴대폰은 스킬 줄(`#skrow`) 왼쪽에 작은 가방 단추 → 4칸. **문제를 푸는 동안에도 힌트 두루마리는 쓸 수 있게**(34-qinfo 의 `body.qhide` 가 가방 단추는 숨기지 않도록 예외).
- 그림: 캔버스로 직접(16×16 아이콘 4개). 새로 받지 않는다.

### R-5. 쓰러짐의 무게 (벌 없이)
- 지금: 쓰러지면 마이룸에서 회복, 벌 없음. 바꾸는 것: **잃는 것은 없고, 지킬 것이 생긴다.**
  - "연속 무사 기록": 쓰러지지 않고 물리친 몬스터 수 `save.st.safe`. 10·25·50에서 칭호 조각/소모품 선물, 쓰러지면 0으로(보상은 이미 받은 것 유지).
  - 쓰러질 때 그 길목 몬스터가 **다 회복되지 않고 다친 채 남는다**(지금 동작 확인 후, 이미 그렇다면 그대로). 
- `lose()` 문구를 "쓰러졌어요… 무사 기록 n에서 멈췄어요. 다시 도전해요!" 로.

### R-6. 옆길 (선택 보스 3곳)
- 막다른 길 8곳(`d1~d8`) 가운데 3곳(d3·d5·d8)에 **선택 보스**(기존 보스 그림을 색만 바꿔 재사용: `MON` 에 새 키, `dr` 은 기존 것 + 색 필터)를 둔다. 조건: 그 부를 끝낸 뒤에만 나타남. 물리치면 유니크 장신구 1개(04b-items 에 3개 추가) + 스킬 조각 2.
- 메인 길 안내(`rawGoal`)는 가리키지 않는다. 일지에 "숨은 강적 0/3" 한 줄.

### S-1. 길목 장치를 단원 수학으로 (새 파일 `src/38-mathroute.js`, 30-routes 를 감싼다)
장치 9종(`RDEV`, `RDB`, 상태 `RD`)은 그대로 두고, **그 부의 단원 낱말**(`unitName(mapPart())`)에 맞는 "수학 판"을 얹는다. 단원에 맞는 판이 없으면 지금 장치 그대로.
| 장치 | 지금 | 수학 판(단원 낱말 → 내용) |
|---|---|---|
| H 꽃길 스위치 | 같은 색 꽃 3송이를 왼쪽부터 | **숫자 꽃**: 꽃 6~8송이에 숫자. 약수·배수 → "12의 약수 꽃만 밟아요" / 분수 → "1/2 과 크기가 같은 꽃" / 소수 → "0.5보다 큰 꽃" / 범위·어림 → "30 이상 40 미만" / 규칙 → "3씩 커지는 차례로". 맞는 꽃을 다 밟으면 보물, 틀린 꽃은 시들었다 다시 핌(벌 없음) |
| A 무너진 다리 | 점프 또는 돌아가기 | **징검돌**: 개울에 숫자 돌 3줄. 식(혼합 계산·분수 덧셈 등 그 단원 한 문제)의 답이 적힌 돌이 떠오름 → 그 돌로 건넘. 틀린 돌은 가라앉아 물가로 되돌아옴. 돌아가는 다리는 그대로 |
| G 움직이는 발판 | 오르내리는 뗏목 | **눈금 뗏목**: 뗏목 옆에 수직선(0~1 또는 0~100). "3/4 지점에서 내려요" 처럼 맞는 눈금에서 내리면 보물 섬. 그냥 건너도 됨 |
| E 숨은 샛길 | 반짝이는 나무 틈 | **표지판 수수께끼**: 길목 표지판에 한 줄("나무를 왼쪽에서 2×3+1 번째"). 계산하면 틈 위치 |
| B 어두운 길 | 등불 곁에 가면 켜짐 | **등불 차례**: 등불에 숫자, 작은 수부터(또는 규칙대로) 켜면 길 전체가 밝아짐. 차례가 틀려도 그 등불 둘레는 밝음 |
