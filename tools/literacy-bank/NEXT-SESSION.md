## 프롬프트

Tesk(교사 대시보드)·Pesk(학생 앱) 프로젝트의 '오늘의 지문' 지문 은행 작업을 이어서 해 줘.
먼저 `tools/literacy-bank/NEXT-SESSION.md`(이 파일)와 `tools/literacy-bank/build.cjs`, 예시로 `tools/literacy-bank/과학-34.cjs`를 읽고 형식을 익힌 뒤 시작해.

- 환경 3~4: 분리배출, 물 아껴 쓰기, 에너지 절약, 일회용품 줄이기, 숲이 하는 일, 꿀벌, 미세먼지, 갯벌, 멸종 위기 동물, 재활용 표시, 음식물 쓰레기, 지렁이와 흙, 도시의 새, 나무 심기, 하천 살리기

### 지문 쓰는 규칙 (지난 작업에서 실제로 자주 걸린 것 포함)
1. 형식은 기존 파일과 같다: `{id, t, p:[문단], g:[[용어,뜻],[용어,뜻]], c, b:[[이름, 내용, 덧붙임, 근거문단]], q:[문제, [보기4], 정답1~4, 근거문단, 해설], e}`
2. 문체는 친구에게 설명하듯 친근한 반말("~야", "~어", "~지"). 지문 안에 강조 표시(굵게, 색 등)를 하지 않는다.
3. 분량(띄어쓰기 포함, `p.join(' ')` 길이):
   - 3~4학년은 4문단, 450자 안팎(검사 범위 350~650)
   - 5~6학년은 5문단, 600~700자(검사 범위 480~850)
   - 심화는 5문단, 문단마다 5문장, 700~800자(검사 범위 650~1100)
   - 지난번에는 늘 짧게 써서 다시 보충했으니, 처음부터 문장을 넉넉히 쓴다.
4. 구조도 빈칸 `{{정답}}`은 정확히 3개이고, 서로 다른 가지의 **'내용' 칸에만** 넣는다. 덧붙임 칸에 넣으면 빈칸으로 세지 않는다.
5. 빈칸 정답은 지문에 글자 그대로 있는 **한글** 낱말이어야 한다. 숫자는 쓰지 않는다(예: `{{30}}` 불가).
6. **용어 풀이(g)의 낱말을 빈칸 정답으로 쓰지 않는다.** 가장 자주 걸린 실수다.
7. 가지는 최대 4개다. 시트 열이 4개라 5개째는 잘린다.
8. 문자열 안에 작은따옴표(')를 쓰지 말고, 강조할 때는 ‘ ’를 쓴다.
9. 사실은 교과서 수준에서 확실한 것만 쓴다. 출처 없는 통계는 쓰지 않는다. 학생 본인의 피해 경험을 묻는 서술형은 내지 않는다.
10. 4번 문제는 지문에 없는 새 상황에 원리를 적용하는 4지선다로, 정답은 하나다.

### 검사
- 한 파일을 쓸 때마다 `node tools/literacy-bank/build.cjs`를 실행한다.
- 모든 파일이 15/15이고, "되읽기 통과"가 전체 편수와 같아질 때까지 고친다. "(주의)" 분량 경고도 없앤다.
- 고칠 때는 수정 목록을 JSON 파일로 만들어 파이썬으로 적용한다. 긴 셸 명령은 인코딩이 깨진다.
- 결과 CSV는 `tools/literacy-bank/literacy-bank.csv`에 만들어진다.

### 2단계: 구글 시트 만들기 (225편 완성 후)
1. 구글 드라이브 연결 도구 `create_file`로 `literacy-bank.csv` 내용을 `contentMimeType: text/csv`로 올려 '오늘의 지문 은행' 시트를 만든다. 구글 시트로 자동 변환된다.
2. 만든 시트 ID를 `shared/literacy-core.js`의 `DEFAULT_BANK_SHEET_ID = ''`에 넣는다.
3. 사용자에게 시트 공유를 **'링크가 있는 모든 사용자 → 뷰어'**로 바꿔 달라고 요청한다. 공유 설정은 사용자가 직접 한다.
4. `shared/literacy-core.js?v=` 버전을 `pesk.html`, `tesk_teacher_v2.html`, `pesk-service-worker.js` 세 곳 모두 새 값으로 올리고, 서비스 워커 캐시 이름(`PESK_CACHE`)도 올린다.

### 3단계: 확인 · 배포 · 커밋
- `node --test --test-isolation=none tests/*.test.cjs`로 전체 테스트를 돌린다.
- `_teacher_ui_preview.html`(미리보기 서버 `tesk-static`, 포트 8765)에서 '오늘의 지문' 메뉴를 확인한다. 지문 은행 불러오기 → 빈 회차 자동 채우기 → 승인 순서다.
- 배포는 `deploy-cloudflare.bat`과 같은 규칙으로 한다. 밑줄로 시작하는 파일과 위젯용 index.html은 빼고, `shared/` 폴더 전체와 자산 파일을 넣는다. 폴더는 `tmp/deploy-날짜-이름`에 만들고 `npx wrangler pages deploy . --project-name=tesk-pesk --branch=main --commit-dirty=true`를 실행한다.
- 배포 전에 운영 사이트 파일이 git 저장본과 같은지 확인한다. 줄바꿈만 다르면 같은 것이다.
- 커밋은 이번 작업 파일만 경로를 지정해서 한다. `git add -A` 금지. 여러 창에서 같은 파일을 편집하기 때문이다.

### 아직 배포·커밋하지 않은 이전 작업 (같이 배포 대상)
마지막 커밋은 `fcc771c`이다. 그 이후 바뀐 것은 다음과 같다.
- `pesk.html`: 오늘의 지문을 모험 탭 안으로 옮김, 이번 주 퀘스트 접기, 마이룸 옷장(가진 것만)과 🛍️ 아이템 상점 분리
- `shared/literacy-core.js`: 수준 3단계(low/high/adv), 지문 은행 CSV 읽기·쓰기(`parseBank`, `toBankRow`, `BANK_COLUMNS`), `DEFAULT_BANK_SHEET_ID`
- `tesk_teacher_v2.html`: 오늘의 지문의 수준 선택, 반 시트 주소, 📚 지문 은행 카드(불러오기, 자동 채우기, 회차에 넣기, 초안 일괄 승인), AI 출력 한도 수정(16,384, thinkingBudget 1024, json)
- `pesk-service-worker.js`: 캐시 v48
- `tools/literacy-bank/`: 지문 150편과 빌드 스크립트
- `_literacy_preview.html`은 예전 시안이므로 커밋하지 않는다.
